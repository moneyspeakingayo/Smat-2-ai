# Contributing

Smart Tech AI is a single-file app: almost everything lives in `index.html`.

1. Fork the repo and create a branch.
2. Run locally: `python3 -m http.server 8080`, then open http://localhost:8080
3. Keep it dependency-free. No build step.
4. Never commit API keys. The Check workflow blocks common key formats.
5. Open a pull request describing what changed and how you tested it.
